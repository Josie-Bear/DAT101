1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Du burde bruke constants når svaret ikke skal endre seg eller hvis det er alltid har et fast svar. Variabler skal brukes i starten av linjen. Ikke alle variabler burde være constant fordi de ikke kan endres når programmet kjøres.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Paranteser bestemmer hva i linjen skal gjøres først, tenk på matte-hyrarkiet.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. We can use toFixed() to set the max number of decimals.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. We can compare two floating-point by using == to see if they are equal to each other. Or use === to see if they are equal value and type.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators return true or false to the two values you have put in. We check if they are true or false by using "0" and other signs.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() works by giving you a number between 0 and 1. It can be used to give you a random number, you can also use it to make bigger numbers by multiplying it. It can also be used with Math.floor or Math.ciel to make it a round number.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. Modulus or % gives us the remainder of a mathematical operation. We need it after an earlier mathematical operation.
